# Repository adoption checklist

- [ ] Owner and actual production code state identified
- [ ] Server-only changes reconciled; secrets exposure addressed
- [ ] Restorable backups and recovery objectives confirmed
- [ ] README and local setup work on a clean machine
- [ ] Synthetic seed data and environment example provided
- [ ] PR protection, independent review and required CI configured
- [ ] Unit/integration/security checks pass
- [ ] Immutable artifact build and digest recorded
- [ ] Staging UAT verifies same artifact as production
- [ ] Migration and application rollback drill passed
- [ ] Deployment audit, monitoring and incident owner defined
- [ ] Direct production source editing disabled
